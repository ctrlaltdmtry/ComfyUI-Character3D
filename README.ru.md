# Character / 3D Editor для ComfyUI

[English](README.md) · [Русский](README.ru.md)

**Версия 0.5.1** · Локальный редактор WebGL2 · Интерфейс RU / EN · Неизменяемые PNG-снимки

Создавайте взрослых 3D-персонажей и настраивайте их позы прямо в ComfyUI, затем сохраняйте композицию через Freeze в `IMAGE` и маску переднего плана `MASK`. В комплект входят графические ресурсы MakeHuman/MPFB и Three.js. Для использования редактора не нужны Blender, диффузионная модель, CDN или внешний API.

## Возможности

- От одного до четырёх независимых персонажей в общей сцене: добавление, дублирование, переименование, размещение и видимость; редактирование выбранного персонажа отдельно от остальных.
- 68 параметров внешности лица и тела: поиск, точные значения, сбросы и перетаскиваемые маркеры формы. Подготовленные взрослые мужская и женская основы.
- Позирование тела и лица: вращательные манипуляторы, FK, двухзвенная IK четырёх конечностей, независимый взгляд, мимика и отдельный сброс лица.
- Независимые камеры результата и навигации; размер холста, фон и прозрачность.
- Конструктор листа ракурсов: до 4 × 4 ячеек со своими камерами и необязательными подписями. Внешность и поза общие для всех ячеек.
- Закреплённые плитки разделов: обычный щелчок выбирает один раздел, Shift+щелчок переключает несколько; есть открытие и закрытие всех разделов.
- Переключение RU / EN без пересоздания форм. Изначально выбран русский; устройство запоминает язык. Значения сцены, имена, подписи и сохранённые снимки не меняются.
- Явный **Freeze** сохраняет неизменяемый PNG. Изменения черновика не перерисовывают прежний результат и не инвалидируют его автоматически.
- Переносимые пакеты `.character3d.zip`: workflow, редактируемые черновики и исходные PNG с проверкой отпечатков рендера и ресурсов.
- Отрисовка по изменениям вместо постоянного цикла анимации в простое.

## Установка

Из каталога `custom_nodes` вашей ComfyUI:

```bash
git clone https://github.com/ctrlaltdmtry/ComfyUI-Character3D.git
```

После установки самостоятельно запустите или перезапустите ComfyUI. Пакет не запускает и не перезапускает сервер. Если браузер показывает старый интерфейс, обновите страницу через Ctrl+F5.

Другой вариант — установка из отдельной копии исходников:

```bash
python tools/install_node.py /path/to/ComfyUI/custom_nodes --dry-run
python tools/install_node.py /path/to/ComfyUI/custom_nodes
```

Для существующего каталога требуется явный `--update`; сначала сохраните резервную копию. Установщик копирует только перечисленные runtime-файлы, проверяет SHA256 и не обновляет зависимости или другие ноды. Посторонние файлы он не удаляет.

Нужны ComfyUI с Python 3.10+, NumPy, Pillow, PyTorch и aiohttp, а также браузер с WebGL2. Обычно эти библиотеки уже есть в окружении ComfyUI. Не заменяйте установленный в ComfyUI PyTorch отдельной сборкой ради этой ноды.

## Первый запуск

1. Добавьте **Character / 3D Editor** из категории **Character/3D** или откройте стартовый пример `examples/character3d-workflow.json`.
2. Нажмите **Редактор / Editor**, настройте внешность, позу и камеры.
3. Нажмите **Freeze → нода / Freeze → node** в редакторе и дождитесь завершения.
4. Подключите `image` к SaveImage или другому входу изображения и запустите workflow.

| Выход | Содержимое |
| --- | --- |
| `image` | Сохранённый RGB-тензор float32 `[B,H,W,C]`, значения `[0,1]` |
| `foreground_mask` | Альфа-покрытие переднего плана float32 `[B,H,W]`; передний план = 1 |
| `scene_json` | Проверенный конверт сохранённой сцены |
| `description` | Необязательное описание |

Маска **не инвертирована**, в отличие от альфа-маски LoadImage. Включите прозрачность перед Freeze, если нужна маска силуэта: непрозрачный фон даёт маску из единиц. Подписи листа входят и в альфа-канал PNG, и в маску. SaveImage получает RGB; для прозрачности сохраняйте маску отдельно или экспортируйте сам PNG.

Экспорт PNG из редактора сохраняет текущий черновик; экспорт PNG из ноды возвращает последний frozen-снимок. Обычный JSON workflow не содержит этот PNG: для переноса используйте пакет Character3D либо отдельно перенесите соответствующий входной PNG. Сохраните текущий граф перед подтверждением импорта пакета: импорт заменяет workflow, но не запускает его.

## Переносимые пакеты

Экспорт и импорт пакета в ноде работают с данными Character3D без нового рендера. Доступен CPU-only CLI:

```bash
python -B tools/character_package.py export workflow.json scene.character3d.zip --input-dir /path/to/source/input
python -B tools/character_package.py inspect scene.character3d.zip
python -B tools/character_package.py import scene.character3d.zip --input-dir /path/to/receiver/input --workflow-out restored.json
```

Выходные имена должны быть новыми. Для редактируемого пакета нужны совпадающие отпечатки кода рендера и ресурсов, а не только номер версии. Различие лишь в номере версии допускается с уведомлением, если отпечатки совпадают. Старые неизменяемые PNG воспроизводятся отдельно; это не означает совместимость всех старых редактируемых пакетов.

Пакет не включает произвольные ноды ComfyUI, веса моделей или входные файлы других расширений. SHA256 проверяет целостность и согласованность данных, но не удостоверяет автора. Загружайте workflow только из доверенных источников.

## Отдельный просмотр без ComfyUI

Из корня репозитория:

```bash
python -m http.server 8767 --bind 127.0.0.1
```

Откройте <http://127.0.0.1:8767/>. Отдельный редактор умеет экспортировать PNG; для Freeze в ноду нужна интеграция с ComfyUI. Ресурсы и рендер локальные, но у самого сервера ComfyUI могут быть свои сетевые настройки.

## Ограничения

Это low-poly параметрический редактор, а не программа скульптинга или законченная система цифрового человека. Параметры лица и тела ещё требуют расширения. Причёски, подробные текстуры кожи, дополнительные анатомические модули, система одежды, ретаргетинг Mixamo, отдельные маски персонажей и независимые позы ячеек листа не реализованы.

IK использует аналитический двухзвенный решатель и ограничения углов, а не биомеханические и коллизионные ограничения. Крайние сочетания форм, мимики и свободных значений могут давать пересечения и искажения; технические тесты не заменяют художественную оценку. Производительность на настоящем слабом GPU или телефоне и универсальное отсутствие утечек не сертифицированы.

При разработке 0.5.1 прошла JavaScript/Python-регрессии, реальные RU/EN-сценарии в CPU/SwiftShader-браузере, проверки Freeze/Save с чтением результата, точное CPU-воспроизведение IMAGE/MASK и перенос пакетов. Это ограниченные результаты разработки, не гарантия для всех версий ComfyUI, интерфейса и устройств. Локальные данные авторизации QA, сырые логи, скрипты установки в основное окружение и внутренние отчёты установки не публикуются.

## Тесты разработки

Из корня репозитория, с современным Node.js, поддерживающим `node:module.registerHooks` (при разработке использовался Node 26), и перечисленными выше Python-зависимостями:

```bash
node --experimental-vm-modules --import ./tests/register-three-alias.mjs --test tests/*.test.mjs
python -B -m unittest discover -s tests -p 'test_*.py'
```

Node-хук перенаправляет импорты Three.js на комплектную версию; `npm install` не нужен. Python-проверкам согласованности также нужен Node в PATH, а HTTP-фикстурам — разрешение на временные локальные порты. Это модульные, контрактные и локальные HTTP-тесты, не запуск основного ComfyUI или нативного браузерного сценария. Часть унаследованных фикстур использует общий путь `~/AppData/Local/hermes/cache/scratch` для изолированных временных данных; это соглашение о каталоге тестов, а не требование установить Hermes. Создаваемые отчёты в `tests/performance/` исключены из Git.

README ресурсов сохраняют исторические заметки о подготовке и проверках. В эту компактную публикацию не входят полные кэши авторских исходников, программы регенерации, нативные браузерные QA-сценарии и привязанные к машине скрипты выпуска и установки. Тесты исключённых инструментов также не включены; прежние итоги полного набора нельзя приписывать этому публичному подмножеству.
